PHP - Éco-conception & Green Coding

PHP Rust Python C/C++ Java Dart JavaScript (bientôt)

PHP se classe 21ᵉ sur 27 en termes d'efficacité énergétique, consommant environ 28× plus d'énergie que C++ pour exécuter les mêmes programmes. Cependant, avec 40-50% des sites web utilisant PHP (WordPress, Drupal, Laravel...), même de petites optimisations ont un impact global significatif.


Cette page présente 10 règles d'éco-conception concrètes pour réduire l'empreinte environnementale de vos applications PHP, avec des exemples de code avant/après et des mesures de gains réels.

Les 10 Éco-Rules PHP

1

concat2implode - Concaténation de chaînes en boucle

#strings #mémoire #performance
×4
Plus rapide
-60%
Mémoire
⭐⭐⭐

Code inefficace : 

$result = '';
foreach ($items as $item) {
    $result .= $item . ', ';
}
$result = rtrim($result, ', ');

Pourquoi c'est inefficace ?

  • Chaque concaténation $result .= ... crée une nouvelle chaîne en mémoire.
  • Pour 1000 éléments, cela peut provoquer 1000 allocations mémoire.
  • Le CPU et la mémoire sont davantage sollicités.

Code optimisé : 

$result = implode(', ', $items);

Gains mesurés :

  • ×4 plus rapide pour les grandes listes.
  • Réduit la consommation mémoire de 60 à 80%.
  • Une seule allocation mémoire au lieu de nombreuses concaténations.
2

echo_concat2comma - Affichages avec virgules

#echo #sortie #mémoire
Modéré
Performance
-30%
Mémoire
⭐⭐

Code inefficace : 

echo 'Bonjour ' . $nom . ', vous avez ' . $age . ' ans.';

Pourquoi c'est inefficace ?

  • La concaténation avec . crée une chaîne temporaire complète.
  • Cette chaîne temporaire consomme de la mémoire inutilement.

Code optimisé : 

echo 'Bonjour ', $nom, ', vous avez ', $age, ' ans.';

Gains mesurés :

  • Réduit l'utilisation mémoire.
  • echo avec virgules envoie directement les morceaux au buffer de sortie.
3

sprintf2direct - Éviter sprintf() inutile

#sprintf #formatage #cpu
×3
Plus rapide
-40%
Mémoire
⭐⭐⭐

Code inefficace : 

$message = sprintf('Utilisateur %s a %d points', $nom, $points);
echo $message;

Pourquoi c'est inefficace ?

  • sprintf() ajoute un coût de parsing du format.
  • Il crée une chaîne temporaire.
  • Pour les cas simples, c'est un surcoût inutile.

Code optimisé : 

// Pour affichage direct :
echo "Utilisateur $nom a $points points";

// Ou avec printf() pour éviter l'allocation temporaire :
printf('Utilisateur %s a %d points', $nom, $points);

Gains mesurés :

  • Temps d'exécution réduit pour les appels répétés.
  • Moins de mémoire utilisée.
4

in_array2isset - Recherche dans tableaux

#tableaux #recherche #complexité
×1000
Plus rapide
O(1)
Recherche
⭐⭐⭐⭐

Code inefficace : 

$allowed_roles = ['admin', 'editor', 'author', 'subscriber'];

if (in_array($user_role, $allowed_roles)) {
    // Accès autorisé
}

Pourquoi c'est inefficace ?

  • in_array() parcourt le tableau séquentiellement.
  • La complexité est en O(n).
  • Sur de grandes listes, cela consomme beaucoup de CPU.

Code optimisé : 

$allowed_roles = [
    'admin' => true,
    'editor' => true,
    'author' => true,
    'subscriber' => true
];

if (isset($allowed_roles[$user_role])) {
    // Accès autorisé
}

Gains mesurés :

  • isset() permet un accès direct.
  • Complexité O(1) au lieu de O(n).
  • Économie CPU importante sur les grandes listes.
5

array_push2direct - Ajout direct aux tableaux

#array #boucle #micro-optimisation
10-20%
Performance
Faible
Mémoire
⭐

Code inefficace : 

$results = [];
foreach ($items as $item) {
    array_push($results, process($item));
}

Pourquoi c'est inefficace ?

  • array_push() est un appel de fonction.
  • Dans une boucle, cet overhead se répète à chaque itération.

Code optimisé : 

$results = [];
foreach ($items as $item) {
    $results[] = process($item);
}

Gains mesurés :

  • Évite l'overhead de l'appel de fonction.
  • Code plus lisible et plus idiomatique en PHP.
6

array_merge_loop - Fusion unique de tableaux

#array_merge #mémoire #complexité
O(n)
Optimisé
Très élevé
Mémoire
⭐⭐⭐⭐

Code inefficace : 

$all_data = [];
foreach ($sources as $source) {
    $all_data = array_merge($all_data, fetch_data($source));
}

Pourquoi c'est inefficace ?

  • array_merge() recrée un nouveau tableau à chaque itération.
  • La complexité peut devenir O(n²).
  • La mémoire est fortement sollicitée.

Code optimisé : 

// PHP 7.4+ avec spread operator :
$arrays_to_merge = [];

foreach ($sources as $source) {
    $arrays_to_merge[] = fetch_data($source);
}

$all_data = array_merge(...$arrays_to_merge);

// Alternative PHP < 7.4 :
$all_data = [];

foreach ($sources as $source) {
    foreach (fetch_data($source) as $item) {
        $all_data[] = $item;
    }
}

Gains mesurés :

  • Complexité O(n²) → O(n).
  • Évite les copies répétées en mémoire.
  • Réduit fortement les opérations CPU.
7

opcache_enabled - Activer OPcache en production

#opcache #production #serveur
×3-5
Plus rapide
Cache
Mémoire
⭐⭐⭐⭐⭐

Configuration inefficace : 

; php.ini
opcache.enable=0

Pourquoi c'est inefficace ?

  • Sans OPcache, PHP recompile les scripts à chaque requête.
  • Le parsing et la compilation sont répétés inutilement.
  • Cela augmente la charge CPU du serveur.

Configuration optimisée : 

; php.ini
opcache.enable=1
opcache.memory_consumption=128
opcache.interned_strings_buffer=8
opcache.max_accelerated_files=10000
opcache.revalidate_freq=60
opcache.validate_timestamps=1  ; 0 en production stricte

Gains mesurés :

  • Performance souvent multipliée par 3 à 5 selon les projets.
  • Réduit fortement la charge processeur.
  • Moins de cycles CPU = moins de consommation électrique.
8

foreach_reference_cleanup - Nettoyage des références

#foreach #références #fiabilité
Évite bugs
Fiabilité
Refs
Libérées
⭐⭐

Code dangereux : 

$items = [1, 2, 3, 4, 5];

foreach ($items as &$item) {
    $item *= 2;
}

// ⚠️ La référence $item persiste !
foreach ($items as $item) {
    echo $item;
}

Pourquoi c'est dangereux ?

  • La référence &$item persiste après le foreach.
  • Elle peut provoquer des modifications inattendues.
  • Cela peut créer des bugs difficiles à repérer.

Code optimisé : 

$items = [1, 2, 3, 4, 5];

foreach ($items as &$item) {
    $item *= 2;
}

unset($item);  // ✅ Libère la référence

foreach ($items as $item) {
    echo $item;
}

Gains mesurés :

  • Évite les bugs de mutation involontaire.
  • Libère la référence orpheline.
  • Rend le comportement du code plus prévisible.
9

empty2isset_check - Vérifications ciblées

#isset #empty #conditions
8-10%
Performance
Faible
Mémoire
⭐

Code inefficace : 

$config = load_config();

if (!empty($config['database']['host'])) {
    connect($config['database']['host']);
}

Pourquoi c'est inefficace ?

  • empty() effectue plusieurs vérifications.
  • Si la variable existe déjà, une vérification plus ciblée peut suffire.

Code optimisé : 

$config = load_config();

if (isset($config['database']['host']) && $config['database']['host']) {
    connect($config['database']['host']);
}

Gains mesurés :

  • Moins d'overhead de vérification.
  • Gain surtout visible dans les boucles ou fonctions très appelées.
10

require2autoload - Autoloading PSR-4

#autoload #composer #architecture
Variable
Performance
Signif.
Mémoire
⭐⭐

Code inefficace : 

// Chargement manuel de toutes les classes
require_once 'models/User.php';
require_once 'models/Product.php';
require_once 'models/Order.php';
require_once 'controllers/UserController.php';
// ... 50 autres fichiers

Pourquoi c'est inefficace ?

  • Charge tous les fichiers même s'ils ne sont pas utilisés.
  • Augmente le temps de parsing et la mémoire utilisée.
  • Rend la maintenance plus difficile.

Code optimisé : 

// Autoloader PSR-4 ou Composer
spl_autoload_register(function ($class) {
    $file = str_replace('\\', DIRECTORY_SEPARATOR, $class) . '.php';

    if (file_exists($file)) {
        require $file;
    }
});

// Les classes sont chargées automatiquement à la demande
$user = new User();

Gains mesurés :

  • Chargement à la demande.
  • Moins de fichiers inutiles en mémoire.
  • Architecture plus propre et maintenable.

Bonnes pratiques complémentaires

Types stricts

declare(strict_types=1);

function calculateTotal(float $price, int $qty): float {
    return $price * $qty;
}

Évite les conversions de types implicites → économie CPU.

Requêtes SQL

// ✅ Une seule requête
$ids = implode(',', $user_ids);

$users = $db->query(
    "SELECT * FROM users WHERE id IN ($ids)"
);

Évite le problème N+1 → moins de connexions réseau.

Générateurs

function getAllRecords($pdo) {
    $stmt = $pdo->query("SELECT * ...");

    while ($row = $stmt->fetch()) {
        yield $row;
    }
}

Mémoire constante au lieu de charger 100 000 lignes.
